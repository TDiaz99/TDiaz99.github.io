REST API overview

The API is JSON over HTTPS. All requests need a bearer token, and all responses are paged.

Authentication

Exchange your client credentials for a token, then send that token on every request. Tokens last one hour.

Copy
Request a token
curl -X POST 'https://api.meridian.example/v1/oauth/token' \
  -H 'Content-Type: application/json' \
  -d '{"client_id":"YOUR_ID","client_secret":"YOUR_SECRET","grant_type":"client_credentials"}'
Copy
Response
{
  "access_token": "eyJhbGciOi...",
  "token_type": "Bearer",
  "expires_in": 3600
}

Never put a client secret in browser code or a mobile app. Request tokens from your own server only.

Make a request

Copy
List active employees
curl -X GET 'https://api.meridian.example/v1/employees?status=active&limit=50' \
  -H 'Authorization: Bearer $TOKEN'

Paging

Responses include a next_cursor when more records exist. Pass it as the cursor parameter to fetch the next page.

Copy
Paged response
{
  "data": [
    { "id": "emp_8Kd21", "legal_name": "A. Okafor", "status": "active" },
    { "id": "emp_9Lm44", "legal_name": "R. Bhatt",  "status": "active" }
  ],
  "has_more": true,
  "next_cursor": "Y3Vyc29yOjUw"
}

Cursors are opaque and short-lived. Do not store them or try to construct one yourself.

Rate limits

Plan Requests per minute Burst
Standard 120 200
Plus 600 900
Enterprise By agreement By agreement

Every response carries X-RateLimit-Remaining and X-RateLimit-Reset. When you exceed the limit you get 429 with a Retry-After header.

Back off exponentially and honour Retry-After. Retrying immediately keeps you rate limited for longer.

Errors

Status Meaning Retry?
400 Malformed request No, fix the request
401 Missing, expired or wrong-environment token Get a new token
403 Token lacks the required scope No, change the scope
422 Valid JSON but failed a business rule No, see the error body
429 Rate limited Yes, after Retry-After
500 Server error Yes, with backoff
Copy
Error body
{
  "error": {
    "code": "invalid_effective_date",
    "message": "Effective date must not fall inside an open pay period.",
    "field": "effective_date"
  }
}

To be told when things change instead of asking, see webhook events.
